# Записи и видео Maytoni для партнёров

Страница со записями вебинаров и обучающими видео Maytoni Academy. Список материалов страница берёт
из листа «Записи и видео» в Google-таблице «Расписание вебинаров для сайта» при каждом открытии,
поэтому сайт обновлять не нужно: тренеры добавляют строки в таблицу.

В репозитории один рабочий файл: `index.html`. Шрифты, логотип и стили уже внутри него.

## Как это работает

1. Тренер выкладывает видео на RuTube (доступ «По ссылке») или другую площадку с открытой ссылкой.
2. Добавляет строку в лист «Записи и видео»: раздел, название и ссылка обязательны, остальное по желанию.
3. Страница при открытии читает лист и сразу показывает новый материал.
4. Если таблица недоступна, страница показывает сохранённую копию списка и пишет об этом внизу.

## Настройка

### Таблица

Таблица: https://docs.google.com/spreadsheets/d/1qn0W7GKEWqei6V1R1sIfkNTxtO3Bg_oeCH5Oy6oqkZw/edit#gid=2001

- Общий доступ: «Все, у кого есть ссылка» → «Читатель». Без этого страница не прочитает лист.
- Тренерам: роль «Редактор» по их почтам.
- Название листа «Записи и видео» и заголовки столбцов не менять: страница ищет лист по названию,
  а столбцы по заголовкам. Порядок столбцов менять можно.

Если нужно подключить другую таблицу или лист, в `index.html` поменяйте строки:

```js
var SHEET_ID='1qn0W7GKEWqei6V1R1sIfkNTxtO3Bg_oeCH5Oy6oqkZw';
var SHEET_NAME='Записи и видео';
```

### GitHub Pages

1. Загрузите `index.html` в корень репозитория (или в папку, если страница живёт рядом с другой).
2. Settings → Pages → Source: Deploy from a branch, ветка `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты страница откроется по адресу вида `https://<аккаунт>.github.io/<репозиторий>/`.

## Сохранённая копия

Внутри `index.html` есть копия списка на 12.11.2026 (32 материала). Она показывается, только если
таблица не открылась. Обновлять её не обязательно.
